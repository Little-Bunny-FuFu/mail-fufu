* 0.1.0 (2026-11-09) - verified working on retail 12.1.x and WoW Forever 1.60.x
- Button layout matched to the EasyMail layout spec. The five inbox toolbar buttons are
  text-less UIPanelButtonTemplate buttons (Blizzard's default red button plate, same family
  as the Game Menu buttons) with original gold glyph overlays generated by
  tools/Generate-Art.ps1 (System.Drawing -> 32-bit TGA in Images): stacked sheets = All,
  one sheet = Page, slot checked = Mark / empty = Clear; icons 34x34 and Get Checked
  112x34 (the EasyMail sizes; the 22 px plate is stretched); Get Checked's right slot shows
  Blizzard's backpack icon (Inv_misc_bag_08). Envelope glyph on the history button. Take All makes 8 px of room on the open-mail panel; the addressee
  dropdown uses the Blizzard chat scroll-arrow files.
- New addon. Clean-room, library-free re-implementation of the EasyMail feature set for
  retail 12.1.x and WoW Forever 1.60.x (Interface 16001). One TOC, runtime feature
  detection for the two Blizzard mail UI shapes (global functions vs mixins).
- Send mail: last addressee per character, recently-mailed list per realm/faction with
  dropdown (Menu API), friends/guild sources, autocomplete through Blizzard's own
  autocomplete source hook, money subject, bags open on the Send tab.
- Inbox: per-mail checkboxes, Mark/Clear All/Page, Get Checked batch collection
  (headless by mail index, COD/GM skip, optional pending-auction delete, 10 s timeout,
  bag-space and inbox-change guards), right-click take/delete with prompt rules, mail
  text in the inbox tooltip, Open All show/enable handling.
- Open mail: Take All (COD-gated), Forward (text only), money-received chat lines.
- History: sent-mail log in its own SavedVariable, history window with realm filter,
  envelope button (left = history, right = options), /mailfufu history and /mailfufu last.
- Options via the Settings API; Defaults never clears lists or history.
- Review fixes before the first test: command pacing on every take, inbox-count based
  completion detection (identical adjacent auction mails), marks kept on mails with
  failed attachments, no bag-space refusal for deletion-only batches, send capture via
  SendMailFrame_SendMail (covers gamepad sends on Forever), result-driven guild roster
  fallback to C_Club.
